## 📌 Описание проекта

**Цель:** Провести комплексный анализ вторичного автомобильного рынка (10 000 объявлений) для выявления ключевых факторов, влияющих на ценообразование, и подготовки рекомендаций для дилеров и покупателей.

**Решаемые задачи:**
- 🔍 Анализ динамики обесценивания автомобилей в зависимости от возраста и пробега
- 📊 Сегментация рынка по брендам, типам трансмиссии и кузову
- 💰 Выявление факторов, влияющих на ценообразование (возраст, пробег, тип трансмиссии)
- 📈 Определение аномалий в ценах (переоцененные и недооцененные авто)
- 🎯 Построение интерактивного дашборда для мониторинга рыночных тенденций

## 📊 Ключевые найденные инсайты

### 1️⃣ Динамика обесценивания (Depreciation Curve)
- **Первые 3-5 лет:** резкое падение стоимости на **30-35%** от первоначальной цены
- **Годы 5-10:** замедление темпа до **3-5% в год**
- **Старше 10 лет:** стабилизация на уровне **15-20% от базовой цены**

**Бизнес-применение:** Дилеры могут оптимизировать оценку при приеме авто на трейд-ин; покупатели понимают справедливую стоимость.

### 2️⃣ Премиум vs Масс-маркет сегментация
| Бренд | Средняя цена | Диапазон цен | Волатильность пробега |
|-------|---|---|---|
| **BMW** | 1.1M | 0.3M - 3.3M | Высокая (+15% чувствительность к км) |
| **Toyota** | 1.1M | 0.4M - 2.9M | Средняя (+10% чувствительность к км) |
| **Hyundai/Kia** | 0.65M | 0.3M - 1.8M | Низкая (+3% чувствительность к км) |
| **Volkswagen** | 0.63M | 0.3M - 2.2M | Средняя (+8% чувствительность к км) |

**Вывод:** Премиум-авто более чувствительны к пробегу — это необходимо учитывать при расчете стоимости.

### 3️⃣ Влияние типа трансмиссии
- **Автомат:** удерживает цену на **15-20% выше** аналогичных моделей на механике
- **Распределение на рынке:** 60% автоматов, 30% механики, 10% роботов
- **Тренд:** растущий спрос на автоматы (+5% в год)

**Бизнес-рекомендация:** Авто с автоматом быстрее продаются, имеют лучшую маржу.

### 4️⃣ Выявленные аномалии ценообразования
- Идентифицировано **15 машин** с ценами выше/ниже рыночной среднего более чем на **20%**
- Пример: Toyota Camry 2014 года переоценена на **+536K** рублей при среднем для года **495K**
- Использовано Window Function `AVG() OVER(PARTITION BY model, year)` для расчета отклонений

## 🔧 Методология анализа

### Фаза 1: Подготовка данных (Data Cleaning & Preprocessing)
```python
# Обработка пропусков
✓ km: Заполнение медианой по году выпуска (группировка для релевантности)
✓ transmission: Заполнение модой (60% - автомат)

# Удаление аномалий
✓ Цены <150K или >12M руб (15 выбросов удалено)
✓ Пробег <100 км (невозможные значения)
✓ Валидация: проверка логичности (возраст ≤ 18 лет, пробег ≤ возраст*30K км)
```

**Статистика очистки:**
- Исходные записи: 10,000
- После очистки: 9,985 (99.85% данных сохранено)
- Пропуски: 300 км (3%), 200 трансмиссия (2%) — обработаны
- Выбросы: 15 аномальных цен — удалены

### Фаза 2: Фичеринжиниринг (Feature Engineering)
```python
# Созданные метрики
✓ car_age = 2026 - year_of_manufacture
✓ km_per_year = km / car_age (среднегодовой пробег для нормализации)
```

### Фаза 3: SQL-анализ (Advanced Analytics)

**Запрос 1: Агрегирующая статистика по брендам**
```sql
SELECT brand, COUNT(*), AVG(price), AVG(car_age), AVG(km)
GROUP BY brand
```

**Запрос 2: Window Functions для поиска аномалий**
```sql
SELECT brand, model, year, price,
  ROUND(AVG(price) OVER(PARTITION BY model, year), 0) as market_avg,
  ROUND(price - AVG(price) OVER(...), 0) as price_deviation
ORDER BY price_deviation DESC
```

**Запрос 3: CTE для выявления лучших предложений**
```sql
WITH RankedCars AS (
  SELECT *, ROW_NUMBER() OVER(PARTITION BY model ORDER BY price ASC) as rank
  FROM cars
  WHERE car_age <= 5
)
SELECT * FROM RankedCars WHERE rank = 1
```
